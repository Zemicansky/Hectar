# Hectar — мониторинг полей

Мобильное PWA-приложение для агрономов: ведение карт полей, учёт агроработ, контроль состояния посевов и погоды — всё в одном месте.

## Функции

### 🗺 Карта и поля
- Интерактивная карта (Leaflet) с переключением слоёв: **Спутник**, **Sentinel-2** (EOX Cloudless, 10 м/пкс) и **Карта** (OSM)
- Нарисовать поле на карте простым тапом по точкам — площадь и периметр считаются автоматически
- Геолокация и поиск мест на карте
- Список полей с фильтрами по культурам и расчётом общей площади

### 📋 Карточка поля
- Название, культура, цвет, площадь, периметр, дата создания
- **История сезона**: события «посев, уборка, полив, опрыскивание, культивация, дискование» с датами и заметками (редактирование и удаление)
- **Стадия вегетации** — автоматически на основе даты посева и культуры
- **Прогноз урожайности** на основе NDVI и культуры
- Фото поля (до 5 шт.)
- 🌲 **Леса и нерабочие зоны** — обводка леса на карте и вычет его площади из площади поля

### 🌿 NDVI-анализ
- Вегетационный индекс на основе **NASA GIBS MODIS Terra** (16-дневный композит, 500 м/пкс)
- Оценка состояния каждого поля, шкала и легенда NDVI, график по месяцам

### 📊 Сезоны
- Управление сезонами (например, «Сезон 2026»)
- Сравнение сезонов по урожайности, осадкам и качеству, график трендов

### 🌦 Погода
- Погода по полям или по городам (Open-Meteo)
- Текущая погода + прогноз на несколько дней
- Избранные города (до 5)
- Рекомендация: ✅ можно / ❌ не рекомендуется опрыскивать

### 📝 Заметки
- Заметки, привязанные к полям, с фильтрами по типу работ (посев, уборка, полив и т.д.)

### 🔐 Аккаунт и синхронизация
- Вход: **Google**, **Email/Пароль** или режим гостя (данные локально)
- Автоматическая синхронизация данных в облаке через **Firebase** (поля, заметки, сезоны, настройки)
- Профиль пользователя, выход, удаление аккаунта
- Языки: русский / английский

### 📱 PWA
- Устанавливается на домашний экран и работает в полноэкранном режиме (iOS/Android)
- Тёмная и светлая темы, поддержка Safe Area (Dynamic Island / notch)

## Технологии

- Чистые HTML / CSS / JavaScript — один файл, без сборки
- **Leaflet** + Leaflet.draw — карта и рисование
- **turf.js** — расчёты площадей и геометрия
- **Firebase** (Auth + Firestore) — авторизация и облачная синхронизация
- **Open-Meteo** — погода и геокодирование
- **NASA GIBS MODIS** — спутниковые данные NDVI
- **EOX Sentinel-2 Cloudless** — спутниковые снимки

## Запуск

Просто откройте `index.html` в браузере (желательно на мобильном устройстве) или разместите файл на любом хостинге.

> Для работы входа и синхронизации вставьте свой `firebaseConfig` в начале блока инициализации Firebase.
